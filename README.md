# Alexia Exports

Static website for Alexia Exports, an Egyptian food exporter.

- `index.html` is the English page.
- `ar.html` is the Arabic page (right to left).
- `logo.png` is the logo, also used as the site icon.

Hosting: GitHub Pages, deployed from the `main` branch, root folder.
To change text, edit the HTML files directly. The phone number and WhatsApp
link appear in both pages.
